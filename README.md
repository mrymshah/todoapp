# To-Do List App 📝

A clean and intuitive React Native To-Do List application built with Expo and TypeScript.

## Features
- ➕ Add new tasks seamlessly
- 🗑️ Delete completed or unwanted tasks
- 📊 Dynamic total task counter
- 📱 Responsive UI styled with modern designs

## Tech Stack
- React Native
- Expo Router
- TypeScript
- Vector Icons (@expo/vector-icons)
